# Pygame Snake

A classic Snake game built with Python and Pygame.

## Features

- Grid-based movement on a 25x25 board
- Snake grows when it eats food
- Collision detection with walls and itself
- Single file, no external assets

## Controls

- Arrow keys: steer the snake

## Run it

Requires Python 3 and Pygame:

    pip install pygame
    python3 snake.py

On Ubuntu, if pip is blocked, use `sudo apt install python3-pygame` instead.

## What I learned

Game loops, handling keyboard input, grid-based movement, and collision logic in Python.
